# Self-explanatory code

Move facts into intent-revealing names, extracted functions, named conditions, constants, enums, checks, and tests. Comments only record a decision reason, rejected alternative, measured future idea, external constraint with source, or code link that must remain synchronized. Do not narrate code or repeat a signature.
