# Accessibility

Use landmarks and ordered headings, links for navigation and typed buttons for actions. Never use positive tabindex or autofocus. Provide labels, legends, error associations, meaningful alternatives, visible focus, sufficient contrast, and live announcements. Use rem units and real table markup.
