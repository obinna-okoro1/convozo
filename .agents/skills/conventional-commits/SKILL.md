# Conventional commits

Use `<type>: <lowercase message>` under 96 characters with no scope, `!`, period, fixup, or squash. Types are feat, fix, chore, docs, test, style, refactor, ci, hotfix, and config. Put ticket ID on the final body line. PR descriptions explain context and final state, never a file walkthrough.
