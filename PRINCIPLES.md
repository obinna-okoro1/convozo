# Principles

- Prefer evidence over assumptions, code over documentation, and efficiency over verbosity.
- Apply SOLID, DRY, KISS, and YAGNI. Prefer composition over inheritance and avoid speculative abstractions.
- Fail fast. Never swallow errors silently.
- Follow the testing pyramid. Add a regression test with every bug fix and a test with every new behaviour.
- Justify each new dependency. Never log secrets or personal data.
